# Markdown → HWPX 변환 예시

1. 개 요
- (배경) 노후설비 교체와 함께 **에너지 절감** 대책 수립 병행 필요
  - (현황분석) **2,100시간/연**의 일조시간으로 태양광 발전 설치조건 유리*
     * 시범 운영 6개월간 실측 데이터를 기준으로 산정한 수치임
    - 인접 동 단위로 확대 적용하면 추가 발전량 확보도 가능
  ☞ 상세 수치는 첨부된 실측 보고서 3쪽 참조
 ※ 신재생에너지 설치는 사내 시설 관리 규정 제4조에 따른다
