# MD2HWPX

## Markdown 포멧의 텍스트를 한글 HWPX 파일로

붙여넣은 Markdown을 템플릿 서식 그대로 HWPX 파일 포멧으로 바꿔 줍니다. 제목·소제목·3단계 불릿·표·박스·하이라이트·각주를 인식합니다.

## 사용 방법은 3단계

1. 화면 우측 상단 **지침(✨)**에서 프롬프트를 복사해 보고서를 작성하던 AI에게 전달합니다
2. AI가 Markdown 형식으로 정리해 준 텍스트를 화면 중앙 에디터에 붙여넣습니다
3. 화면 우측 하단의 **다운로드 버튼**을 누르면 HWPX 파일로 저장됩니다

## 100% 브라우저 처리

입력한 문서와 템플릿은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다. 한글에서 서식을 고친 템플릿(.hwpx)을 화면 좌측 하단에 등록해 쓸 수도 있으며, 이 또한 브라우저에서만 임시 저장됩니다.
